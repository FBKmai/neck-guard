# 颈椎卫士 NeckGuard

用放在身体侧面的手机摄像头，连续检测头部是否明显前倾（"乌龟颈"）。平时低帧率巡检，发现疑似前倾立即切到高帧率确认，确认后在本机弹出通知并附带当时的截图（画有耳肩髋连线和角度），也可同步推送到局域网内的电脑。

- 检测端：Android 手机（前台服务常驻，锁屏后仍能工作）
- 识别模型：MediaPipe Pose Landmarker（本机推理，图像不上传）
- 判定方式：侧视图下耳肩连线与髋肩连线（躯干线）的夹角，即头相对自己身体前伸了多少；支持个人基线校准、迟滞、连续窗确认与冷却
- 后续阶段：上报服务器并推送到主手机、独立硬件小盒子（见 [docs/DESIGN.md](docs/DESIGN.md)）

## 获取 APK

本机没有 Android SDK，打包走 GitHub Actions：

1. 把仓库推送到 GitHub 的 `main` 分支，`android/` 目录有改动时会自动触发 `Build Android APK`。
2. 也可以在仓库页面 `Actions` -> `Build Android APK` -> `Run workflow` 手动触发。
3. 构建完成后，在该次运行页面下载 artifact `neck-guard-debug-apk`，解压得到 `app-debug.apk`。
4. 用数据线、微信文件传输或任意方式把 APK 传到手机安装（debug 签名，首次安装需允许"安装未知来源应用"）。

构建过程会自动从 Google 官方地址下载 `pose_landmarker_lite.task` 模型文件（约 5.8 MB），不需要手动提交到仓库。

## 安装与首次使用

1. 打开应用，授予"相机"和"通知"权限。相机画面只在本机分析，不会上传。
2. 摆放手机（摆放/校准页会实时显示预览和检测状态）：
   - 手机竖放，摄像头正对身体的正侧面
   - 距离 1 到 1.5 米，高度与肩膀齐平
   - 画面里要同时看到耳朵、肩膀和髋部。前倾角以髋肩连线为基准，看不到髋部的帧不参与判定，状态会显示"髋部不可见"
3. 等预览上方的状态显示"已对齐"。如果显示"未对齐"，说明摄像头没有在正侧面，调整角度直到肩偏比降到 0.35 以下。
4. 端正坐好，点"校准"，保持 3 秒。校准成功后会显示基线角度和报警阈值（基线 + 12°，限制在 20° 到 50° 之间）。不校准也能用，此时使用 35° 绝对阈值。
5. 点"开始监测"。应用会切到监测页，通知栏出现常驻通知"颈椎卫士正在监测"。
6. 此时可以锁屏。摄像头保持开启，平时约每秒 1.4 帧巡检；连续 2 帧超过阈值就切到约 8 fps 确认，连续两个确认窗都判定前倾时弹出提醒并附带截图。坐正后会收到一条静音的"已恢复"提示。
7. 停止监测：监测页的"停止"按钮，或常驻通知上的"停止监测"。

监测页实时显示当前角度、帧状态、推理耗时、镜头与委托信息，以及最近的确认窗、前倾事件和截图。

## 国产 ROM 后台保活

前台服务在原生 Android 上不会被杀，但小米、华为、OPPO、vivo 等定制系统默认会清理后台。请按以下通用步骤设置一次：

1. 电池优化：`设置` -> `电池` -> 找到"颈椎卫士" -> 选择"无限制" / "不优化" / "允许后台高耗电"。
2. 自启动：`设置` -> `应用管理` -> `颈椎卫士` -> 允许"自启动"和"后台运行" / "关联启动"。
3. 锁定后台：打开最近任务列表，把颈椎卫士卡片下拉或长按，选择"锁定"，避免一键清理时被杀。
4. 通知：确认"前倾提醒"渠道允许弹出横幅和震动，"监测状态"渠道不要关闭（关闭后前台服务可能被系统限制）。
5. 小米额外：`设置` -> `应用设置` -> `颈椎卫士` -> `省电策略` 选"无限制"；华为额外：`设置` -> `应用` -> `应用启动管理` 关闭自动管理，手动打开全部三项。

各品牌菜单名称略有差异，核心就是三件事：不省电、允许自启动、允许后台运行。

## 参数说明

所有参数在"设置"页可调，保存后立即生效。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 巡检间隔 | 700 ms | 平时每隔多久分析一帧，约 1.4 fps |
| 确认间隔 | 125 ms | 确认模式下每隔多久分析一帧，约 8 fps |
| 确认窗长度 | 3 s | 每个确认窗的时长，约 24 帧 |
| 触发帧数 | 2 | 巡检中连续多少帧超阈值就进入确认 |
| 恢复帧数 | 5 | 前倾后连续多少帧低于退出线才算恢复端正 |
| 重新确认间隔 | 30 s | 确认前倾后至少隔多久才再次进入确认 |
| 无效窗上限 | 2 | 确认模式下连续多少个无效窗就退回巡检 |
| 绝对阈值 | 35° | 未校准时使用的前倾角报警线 |
| 校准增量 delta | 12° | 校准后阈值 = 基线 + delta，并限制在 20° 到 50° |
| 迟滞 hysteresis | 4° | 进入前倾需超过阈值，退出需低于阈值减 4°，避免临界抖动 |
| 最少有效帧 | 8 | 一个确认窗内有效帧不足时该窗判为无效，不计入连续计数 |
| 连续窗数 K | 2 | 连续 K 个确认窗都前倾才确认并通知，约 6 秒 |
| 冷却 cooldown | 10 min | 两次通知之间的最小间隔，冷却期内只记录不通知 |
| 肩偏比上限 | 0.35 | 左右肩水平距离 / 躯干长度，超过则认为摄像头不在正侧面 |
| 必须看到髋部 | 开 | 开启时髋不可见的帧不参与判定；关闭则退回"与竖直线的夹角"继续判定，但躺卧时会误报 |
| 镜头 | 前置 | 可选前置 / 后置 / 后置超广角；部分机型不向第三方开放超广角，会自动退回普通后摄并在界面说明 |
| 分析分辨率 | 640x480 | 可选 960x720 / 1280x960，截图更清晰但开销更大 |
| GPU 加速 | 关 | 部分机型 GPU 委托不可用，失败会自动回退 CPU |
| 坐正后提醒到 | 手机 | 可选不提醒 / 手机 / 电脑 / 两者 |

### 角度定义

**前倾角 = 耳肩连线与髋肩连线（躯干线）的夹角**，衡量的是头相对自己身体前伸了多少。头和身体在一条直线上时为 0°，头越往躯干前方伸角度越大。

v0.4 及更早用的是"耳肩连线与竖直方向的夹角"，那个定义把身体整体的倾斜也算了进去：躺着时头和身体明明成一条直线，耳肩连线却是水平的，算出 90° 必然误报；伏案时躯干前倾 10°，颈部角度也凭空多 10°。同一组关键点在两种口径下的对照：

| 姿势 | 相对躯干线（现在） | 相对竖直线（旧） |
|------|------|------|
| 躺平，头与身体共线 | 0° | 90°（误报） |
| 躺着但头真的前伸 | 44.6° | 45.4° |
| 端坐、头明显前伸 | 36.9° | 36.9° |
| 伏案躯干前倾 20°，头随身体 | 2.5° | 8.4° |

新口径扣掉了躯干本身的前倾，同样姿势算出的角度更小，所以默认阈值一并从 40° 降到 35°。**从旧版本升级上来的话基线会被清空**，摆放页会显示"未校准"，重新校准一次即可。

躯干倾角（髋肩连线与竖直方向的夹角）仍然记录并显示在截图和监测页上，但不参与判定。

## PC 原型（tools/）

用于在电脑上用照片或摄像头验证算法和阈值，算法与 Android 端一字不差。

```powershell
cd tools
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

本机 Python 需为 3.11 或 3.12（mediapipe 1.0.1 暂不支持 3.13）。如果下载依赖或模型走不通，先设置代理：

```powershell
$env:HTTP_PROXY  = "http://127.0.0.1:2080"
$env:HTTPS_PROXY = "http://127.0.0.1:2080"
```

批量分析一个目录里的侧面照片，输出每张的颈部角度、躯干角度、对齐状态，并把带标注的图写到 `tools/output/`：

```powershell
python posture_probe.py --image C:/path/to/samples
```

实时摄像头模式（按 `c` 校准，按 `q` 退出）：

```powershell
python posture_probe.py --camera 0
```

首次运行会自动下载 `pose_landmarker_lite.task` 到 `tools/models/`。

## 电脑端接收（局域网）

手机和电脑在同一 Wi-Fi 下，可把前倾事件与截图同步发到电脑，由电脑弹 Windows 通知并响铃：

1. 电脑上运行 `pc/run_receiver.bat`（或 `python pc/neck_receiver.py --token 你的密钥`）。首次启动会弹一次 UAC 自动放行防火墙，允许即可。
2. 手机 App「设置」页的「电脑接收端」区块：点「扫描电脑」，选中这台电脑，地址会自动填好。
3. 填上与 `--token` 一致的共享密钥，打开「上报到电脑」，点「测试连接」与「发送测试事件」确认。
4. 之后每次前倾提醒都会同时发到电脑。详细参数、发现协议与接口说明见 `pc/README.md`。

之所以用扫描而不是手填：电脑上常有 VMware、WSL、Hyper-V 装的虚拟网卡，`ipconfig` 会列出好几个 IP，手填挑错就会「连接被拒绝」。扫描时地址由电脑按手机所在网段算出，不会填错。

## 监测页的事件记录

- 「最近确认窗」：每个确认窗一张卡片，显示中位角度、判定与代表帧缩略图，点开可看大图。
- 「前倾事件」：每次确认前倾会保存该窗内超过阈值的多帧截图（最多 6 张，按时间均匀抽样），每帧标注各自角度，点任意一张进入全屏左右滑动预览。

## 隐私

- 相机画面只在手机本机推理，不经过网络。
- 摄像头在监测期间保持开启（相机指示灯会常亮），画面只在本机分析，不会上传；停止监测即释放。
- 截图保存在应用私有目录（`files/snapshots/`），只保留最近 300 张（每次前倾最多 6 帧、每个确认窗 1 帧），卸载应用即全部删除。
- 事件日志是本地 JSONL 文件，只记录时间、角度、阈值和截图路径。
