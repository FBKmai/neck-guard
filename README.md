# 颈椎卫士 NeckGuard

用放在身体侧面的手机摄像头，不定时检测头部是否明显前倾（"乌龟颈"）。确认前倾后，在本机弹出通知并附带当时的截图（画有耳肩髋连线和角度）。

- 检测端：Android 手机（前台服务常驻，锁屏后仍能工作）
- 识别模型：MediaPipe Pose Landmarker（本机推理，图像不上传）
- 判定方式：侧视图下耳肩连线与竖直方向的夹角，支持个人基线校准、迟滞、连续窗确认与冷却
- 后续阶段：上报服务器并推送到主手机、独立硬件小盒子（见 [docs/DESIGN.md](docs/DESIGN.md)）

## 获取 APK

本机没有 Android SDK，打包走 GitHub Actions：

1. 把仓库推送到 GitHub 的 `main` 分支，`android/` 目录有改动时会自动触发 `Build Android APK`。
2. 也可以在仓库页面 `Actions` -> `Build Android APK` -> `Run workflow` 手动触发。
3. 构建完成后，在该次运行页面下载 artifact `neck-guard-debug-apk`，解压得到 `app-debug.apk`。
4. 用数据线、微信文件传输或任意方式把 APK 传到手机安装（debug 签名，首次安装需允许"安装未知来源应用"）。

构建过程会自动从 Google 官方地址下载 `pose_landmarker_lite.task` 模型文件（约 5.8 MB），不需要手动提交到仓库。

## 安装与首次使用

1. 打开应用，授予"相机"和"通知"权限。相机画面只在本机分析，不会上传。
2. 摆放手机（摆放/校准页会实时显示预览和检测状态）：
   - 手机竖放，摄像头正对身体的正侧面
   - 距离 1 到 1.5 米，高度与肩膀齐平
   - 画面里要同时看到耳朵和肩膀，最好也能看到髋部
3. 等预览上方的状态显示"已对齐"。如果显示"未对齐"，说明摄像头没有在正侧面，调整角度直到肩偏比降到 0.35 以下。
4. 端正坐好，点"校准"，保持 3 秒。校准成功后会显示基线角度和报警阈值（基线 + 12°，限制在 30° 到 50° 之间）。不校准也能用，此时使用 40° 绝对阈值。
5. 点"开始监测"。应用会切到监测页，通知栏出现常驻通知"颈椎卫士正在监测"。
6. 此时可以锁屏。服务每隔约 30 到 60 秒打开一次摄像头采样 3 秒，连续两次采样都判定前倾时，弹出提醒通知并附带截图。
7. 停止监测：监测页的"停止"按钮，或常驻通知上的"停止监测"。

启动后 3 秒会立刻做第一次采样，方便确认工作正常。监测页可以看到上次采样角度、下次采样倒计时、最近事件列表和截图。

## 国产 ROM 后台保活

前台服务在原生 Android 上不会被杀，但小米、华为、OPPO、vivo 等定制系统默认会清理后台。请按以下通用步骤设置一次：

1. 电池优化：`设置` -> `电池` -> 找到"颈椎卫士" -> 选择"无限制" / "不优化" / "允许后台高耗电"。
2. 自启动：`设置` -> `应用管理` -> `颈椎卫士` -> 允许"自启动"和"后台运行" / "关联启动"。
3. 锁定后台：打开最近任务列表，把颈椎卫士卡片下拉或长按，选择"锁定"，避免一键清理时被杀。
4. 通知：确认"前倾提醒"渠道允许弹出横幅和震动，"监测状态"渠道不要关闭（关闭后前台服务可能被系统限制）。
5. 小米额外：`设置` -> `应用设置` -> `颈椎卫士` -> `省电策略` 选"无限制"；华为额外：`设置` -> `应用` -> `应用启动管理` 关闭自动管理，手动打开全部三项。

各品牌菜单名称略有差异，核心就是三件事：不省电、允许自启动、允许后台运行。

## 参数说明

所有参数在"设置"页可调，改动后在下一个采样窗生效。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 采样间隔 interval | 45 s | 两次采样窗之间的基础等待时间 |
| 随机抖动 jitter | ±15 s | 叠加在间隔上的随机偏移，实现"不定时"检测 |
| 采样窗长度 window | 3 s | 每次打开摄像头连续分析的时长，约 15 到 30 帧 |
| 绝对阈值 | 40° | 未校准时使用的颈部倾角报警线 |
| 校准增量 delta | 12° | 校准后阈值 = 基线 + delta，并限制在 30° 到 50° |
| 迟滞 hysteresis | 4° | 进入前倾需超过阈值，退出需低于阈值减 4°，避免临界抖动 |
| 最少有效帧 | 8 | 一个采样窗内有效帧不足时该窗判为无效，不计入连续计数 |
| 连续窗数 K | 2 | 连续 K 个采样窗都前倾才确认并通知，约 1.5 到 2 分钟 |
| 冷却 cooldown | 10 min | 两次通知之间的最小间隔，冷却期内只记录不通知 |
| 肩偏比上限 | 0.35 | 左右肩水平距离 / 躯干长度，超过则认为摄像头不在正侧面 |
| 前置摄像头 | 开 | 手机屏幕朝向自己时用前置，可切换 |
| 每窗保存快照 | 关 | 调试用，打开后每个有效采样窗都存图并记事件 |

角度定义：耳朵到肩膀的连线与竖直向上方向的夹角。耳朵在肩正上方为 0°，头越往前伸角度越大。临床上常用的颅椎角 CVA 约等于 90° 减去这个角，CVA 小于 50° 视为头前倾，与 40° 的默认阈值对应。

## PC 原型（tools/）

用于在电脑上用照片或摄像头验证算法和阈值，算法与 Android 端一字不差。

```powershell
cd tools
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

本机 Python 需为 3.11 或 3.12（mediapipe 1.0.1 暂不支持 3.13）。如果下载依赖或模型走不通，先设置代理：

```powershell
$env:HTTP_PROXY  = "http://127.0.0.1:2080"
$env:HTTPS_PROXY = "http://127.0.0.1:2080"
```

批量分析一个目录里的侧面照片，输出每张的颈部角度、躯干角度、对齐状态，并把带标注的图写到 `tools/output/`：

```powershell
python posture_probe.py --image C:/path/to/samples
```

实时摄像头模式（按 `c` 校准，按 `q` 退出）：

```powershell
python posture_probe.py --camera 0
```

首次运行会自动下载 `pose_landmarker_lite.task` 到 `tools/models/`。

## 电脑端接收（局域网）

手机和电脑在同一 Wi-Fi 下，可把前倾事件与截图同步发到电脑，由电脑弹 Windows 通知并响铃：

1. 电脑上运行 `pc/run_receiver.bat`（或 `python pc/neck_receiver.py --token 你的密钥`），记下打印出的地址，例如 `http://192.168.1.23:8765`。
2. 手机 App「设置」页的「电脑接收端」区块：填地址与密钥，打开「上报到电脑」，点「测试连接」与「发送测试事件」确认。
3. 之后每次前倾提醒都会同时发到电脑。详细参数、防火墙放行与接口说明见 `pc/README.md`。

## 监测页的事件记录

- 「最近采样」：每次采样窗一张卡片，显示中位角度、判定与代表帧缩略图，点开可看大图。
- 「前倾事件」：每次确认前倾会保存该窗内超过阈值的多帧截图（最多 6 张，按时间均匀抽样），每帧标注各自角度，点任意一张进入全屏左右滑动预览。

## 隐私

- 相机画面只在手机本机推理，不经过网络。
- 只在采样窗内打开摄像头，窗外释放，相机指示灯不会常亮。
- 截图保存在应用私有目录（`files/snapshots/`），只保留最近 300 张（每次前倾最多 6 帧、每次采样 1 帧），卸载应用即全部删除。
- 事件日志是本地 JSONL 文件，只记录时间、角度、阈值和截图路径。
